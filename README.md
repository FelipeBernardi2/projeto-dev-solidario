# Dev Solidário

## Sobre o projeto

O **Dev Solidário** é um projeto acadêmico desenvolvido no contexto das disciplinas de Análise e Projeto de Software e Programação Web.

O objetivo é desenvolver uma aplicação web que coloque em prática os conhecimentos adquiridos durante o curso, desde a concepção e organização do projeto até o desenvolvimento da interface utilizando tecnologias web.

O projeto busca aplicar conceitos de análise, planejamento, estruturação e desenvolvimento de software, promovendo a colaboração entre os integrantes da equipe.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade da interface.
- **JavaScript:** implementação de funcionalidades interativas.

## Estrutura do projeto

A estrutura inicial de diretórios está organizada da seguinte forma:

```text
Dev-Solidario/
├── css/
│   └── style.css
├── img/
│   └── imagens do projeto
├── js/
│   └── script.js
├── index.html
└── README.md
```

A estrutura poderá ser modificada durante o desenvolvimento, conforme a necessidade de novas páginas, recursos e funcionalidades.

- **`css/`**: contém os arquivos responsáveis pela estilização do site.
- **`img/`**: armazena as imagens utilizadas no projeto.
- **`js/`**: contém os scripts JavaScript responsáveis pela interatividade.
- **`index.html`**: página inicial da aplicação. Outras páginas HTML poderão ser adicionadas conforme a evolução do projeto.
- **`README.md`**: documentação com informações sobre o projeto.

## Objetivos acadêmicos

- Aplicar conceitos de Análise e Projeto de Software.
- Desenvolver uma aplicação web utilizando HTML, CSS e JavaScript.
- Organizar arquivos e recursos de acordo com suas responsabilidades.
- Praticar a colaboração e o desenvolvimento de projetos em equipe.
- Documentar o projeto e acompanhar sua evolução.

## Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Explore as páginas e funcionalidades disponíveis.

Durante o desenvolvimento, recomenda-se utilizar um editor de código, como o Visual Studio Code, para facilitar a edição e manutenção dos arquivos.
